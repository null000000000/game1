# Random Challenge Game — Project Pack

حزمة ملفات المشروع المعتمدة للنسخة الأولى من لعبة التحديات العشوائية.

## محتويات الحزمة

| الملف | الغرض |
|---|---|
| `01-brand-identity.md` | استراتيجية البراند والاتجاه البصري المعتمد |
| `02-prd.md` | متطلبات المنتج ونطاق الـMVP ومعايير القبول |
| `03-ux-flows.md` | تدفقات المستخدم ومواصفات الشاشات |
| `04-motion-design-system.md` | نظام الأنيميشن والحركة |
| `challenges.json` | قاعدة بيانات الـ100 تحدي |
| `06-technical-specification.md` | البنية التقنية والمنطق والحفظ |
| `07-google-ai-studio-build-prompt.md` | Prompt جاهز لبدء التنفيذ في Google AI Studio |

## القرارات المثبتة

- المنتج: Random Challenge Game (اسم عمل مؤقت فقط).
- الاتجاه البصري: Playful Minimal.
- لوحة الألوان: Palette D المعتمدة.
- Light Mode فقط.
- 100 تحدي ثابت، موزعين بالتساوي على 5 فئات.
- السحب عشوائي دون تكرار حتى استهلاك دورة الـ100 تحدي.
- لا يوجد اقتراح تحديات من المستخدمين أو إرسال تحديات للأصدقاء.
- الأنيميشن جزء أساسي من تجربة المنتج.
- MVP يعمل دون حساب أو Backend، مع حفظ محلي للتقدم.

## ترتيب الاستخدام

1. راجع `01-brand-identity.md` لتطبيق الألوان والطابع.
2. استخدم `02-prd.md` كنطاق ملزم للنسخة الأولى.
3. نفّذ الشاشات حسب `03-ux-flows.md`.
4. نفّذ الحركة حسب `04-motion-design-system.md`.
5. أرفق `challenges.json` كما هو؛ لا تعِد توليد التحديات.
6. اتبع `06-technical-specification.md`.
7. انسخ `07-google-ai-studio-build-prompt.md` إلى Google AI Studio وأرفق ملفات المشروع.

## ملاحظات

- لم يتم اعتماد اسم نهائي أو لوجو بعد؛ لا تخترع واحدًا في الكود.
- النصوص الحالية باللهجة المصرية، ويمكن إضافة الإنجليزية لاحقًا دون تغيير منطق اللعبة.
- ملف التحديات يتضمن قواعد أمان عامة وملاحظات لبعض التحديات التي تحتاج احتياطًا.
